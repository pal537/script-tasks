# 脚本定时任务（script-tasks）

飞牛 fnOS 原生定时任务应用：小而精，单机能定时执行的东西全支持。

三种任务类型：

- **脚本文件**：上传或新建 `.sh` / `.py`，按后缀自动选 bash / python3 执行
- **命令**：直接填写任意命令，以 bash 执行
- **HTTP 请求**：定时发送 HTTP 请求（方法/URL/请求头/请求体可配），返回 2xx 视为成功

## 功能

- 图形化周期：间隔 / 每天 / 每周 / 每月，不用记 cron 语法；也支持自定义表达式
- cron 高级模式：标准 5 段，或 6 段（含秒）表达式；填写时即时预览下 5 次运行时间
- 失败重试：可设重试次数与间隔
- 超时终止：可设最长运行时间，超了自动杀掉
- 防重叠：上次没跑完，到点不叠开新实例
- 链式运行：任务成功后可接着运行另一个任务（成环自动跳过）
- 实时日志：运行中即可查看输出，可中途停止；日志可复制
- 日志自动清理：按保留天数自动删除（默认 30 天），另有每任务份数上限
- 失败标记：上次失败/超时的任务在列表里红标显示，打开即见
- 备份与恢复：设置里可导出/导入全部任务与脚本，支持下载到本地或存到 NAS 目录
- 走飞牛同源网关接入，桌面端与手机 APP 均可直接打开；任务以 root 运行，数据仅存本机

## 备份与恢复

设置 → 备份：

- 备份内容：全部任务（周期、命令、HTTP、高级设置、衔接任务）与脚本文件；不含运行历史与日志
- 导出：下载到本地，或存到 NAS 数据目录下的 `backups` 文件夹
- 导入：本地上传，或从 NAS 的 `backups` 文件夹里选取；导入为整包替换当前全部任务与脚本，运行中的任务需先停止
- 导入前会全量校验，校验不过整包拒绝、原数据不动；老版本数据的数值（如重试间隔）会自动按现行规则修正

明确不做：消息通知、多节点分布式、多用户与权限体系、数据库、AI 功能——保持小而精。

## 安装

到 [Releases](https://github.com/pal537/script-tasks/releases) 下载 `.fpk`，在飞牛应用中心 → 手动安装里上传安装。仅支持 x86 机型。

仓库已按 FnDepot V2 规范备好 `fnpack.json`，被 FnDepot / Moo 等第三方商店收录后可直接在商店内安装更新。

## 构建

需要 Go 与 [fnpack](https://github.com/ewedlcm/fnpack)：

```bash
./build.sh   # 产出 script-tasks.fpk
```

源码在 `src/`（单个 Go 文件 + 内嵌页面，无第三方依赖），打包骨架在 `package/`。
